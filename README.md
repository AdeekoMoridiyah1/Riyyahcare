# Riyyahcare Health

Riyyahcare is a static, responsive healthcare website. Visitors can explore healthcare services, departments, doctors, and team information, find answers to common questions, and use the contact page to request an appointment.

## Pages

- `index.html` — Home
- `About.html` — About Riyyahcare
- `Document.html` — Departments
- `Services.html` — Services
- `Doctors.html` — Doctors
- `Our-Team.html` — Our team
- `FAQ.html` — Frequently asked questions
- `Contact.html` — Contact and appointment request

## Run locally

No build step or package installation is required. Open `index.html` in a browser, or serve the project directory with a local static web server and visit its local URL.

Bootstrap 5 and Bootstrap Icons are loaded from jsDelivr, so those resources require an internet connection. Page styles, scripts, and image assets are stored in this repository.

## Project structure

- HTML files contain the individual pages.
- CSS files provide shared and page-specific styling.
- `site-pages.js`, `about.js` provide page interactions.
- `asset/`, `asset2/` contain images used across the site.
